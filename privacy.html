Privacy policy

Last updated: October 14, 2026.

jarvis-mail is a private tool used by one person, its owner, on the owner's own computer. It connects to the owner's own Gmail accounts through the Gmail API and to no one else's.

What it accesses

With the owner's consent it reads message headers and text, searches mail, and marks messages as read (the gmail.modify scope). It does not send, delete or move mail.

What it does with the data

Mail is read to sort it into needs attention, marketing and informational. For messages that simple rules cannot settle, the sender, subject and message text are passed to Anthropic's Claude model to classify, under Anthropic's own terms. The results (a short summary line per message) are saved in files on the owner's computer.

Storage and sharing

Sign-in tokens and results stay on the owner's computer. There is no jarvis-mail server and no database. Data is not sold, shared with advertisers, or used to train models or serve ads, and no person reads it other than the owner.

Google API Services User Data Policy

jarvis-mail's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions, and can delete the local files.
